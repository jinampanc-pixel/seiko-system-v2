Jinam Independent Backups

Jinam manages orders, customers, production work, billing and payments for the owner's businesses. Its independent backup runner saves dated encrypted copies of the business database for recovery.

The shared Cloudflare D1 database holds live saved records. Configured Windows and Mac computers can keep their own encrypted copies. An independently configured GitHub Actions job can save a Google Drive copy when those computers are off.

Google Drive access

The runner requests access only to files created by or explicitly opened with this application. It creates a private folder named “Jinam Automatic Encrypted Backups”, uploads encrypted archives and verification manifests, and downloads those encrypted bytes to verify their hashes. It does not request access to Gmail, contacts, calendars or the whole Drive.

Setup and successful verification are required before any destination counts as a backup. Signing in to Jinam alone does not configure a computer backup.
