# Usability review — 24 October 2026

Scope: source review of Home, order workspace, order service, Billing, document output and production; live checks of Home, workspace, search and Billing. This is a follow-up backlog, not a claim that every workflow has been device-tested.

| Priority | Finding | Simplification |
| --- | --- | --- |
| High | Document output offers Prepare PDF, Print / Save PDF and Open full document together, then more file actions. | Keep download and print clear; group alternate views and zoom in document options. Preserve the fresh user gesture needed for mobile sharing. |
| High | The order workspace still has repeated explanatory paragraphs above entry and inside synchronization tools. | Keep status and errors visible; put instructional text in contextual help. Keep manual, voice and pasted-list entry as equally available choices. |
| High | Pricing, deliveries and queries share a long destination name and five service sections. | Keep the order context visible, use shorter task names and reveal only fields relevant to the chosen task. Do not hide eligibility or pricing problems that affect charges. |
| Medium | Home repeats order/module entry points in cards, six daily actions, Quick access and the navigation menu. Its subtitle describes implementation rather than today's work. | Retain user-configurable shortcuts, reduce repeated explanatory text, and review which shortcuts users actually need before removing actions. |
| Medium | Measurement entry has optional batch defaults, person overrides, advanced metadata and voice help. | Reveal these only in context; keep the normal path to person details and the required measurements short. No repeated garment selection when setup already resolves it. |
| Medium | Production uses several terms: sheet, handoff, allocation and demand. | Use consistent user-facing terms; keep planning tools optional. Keep issued work and new order changes distinguishable so production quantities remain accurate. |

Already addressed: app-wide in-app search, global Settings moved out of Billing, billing table corners, guided entry using setup quantities, compact Sheet headers, and pasted-list entry through the existing method selector.

Next review should use a fresh order on a phone: setup → choose any entry method → measure several people → correct one → production counts → invoice → save/share PDF. Measure taps and scrolling; do not remove a control solely because it exists in multiple modules. Changes in this backlog should be made in coherent workflow groups, with permission and data-integrity checks retained.
