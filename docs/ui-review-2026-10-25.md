### Setup rules requiring user attention

Group rules match the selected field only. A rule containing “11 Male” will not match Class = “11” plus a separate Gender = “Male”. The setup now explains this; multi-field conditions are not implemented by this change. The supplied T Shirt / Waist sharing may be intentional and has not been automatically altered. The unsaved order draft was not touched.
