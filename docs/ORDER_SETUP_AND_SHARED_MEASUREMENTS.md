# Order setup, shared measurements and SEIKO palette

Opening an existing order opens its setup. Open workspace is available in the header on desktop and in the bottom action bar on phones. Context menus retain the direct workspace shortcut.

Any measurement can be associated with multiple products using its Used for control in setup. A shared measurement has one workspace entry per person; the saved value is mirrored to the product keys used by labels and production. Existing independent measurements stay independent. Conflicting legacy values are preserved and flagged for an explicit common value, rather than choosing one silently. Sharing a measurement does not establish that a person receives every associated product.

SEIKO uses cream (#fbf5ed), navy (#173c5e), and gold (#c3a06c). Original logos and machine-readable images are preserved. Other businesses retain their themes. The SEIKO theme preference version is advanced so old device overrides do not mask the new default.

Browser coverage includes shared values saved across three products; setup/workspace at 360, 390 and 768 pixels; reopening with exhausted device storage; and Settings/access dialogs with visible save controls. Tests use synthetic records.
